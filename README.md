# Modeling-the-Impact-of-Contamination-on-Microbial-Enzyme-Dynamics-and-Soil-Function

MATLAB code for:
Vafaie, S., Goodey, N.M., Krumins, J.A., Forgoston, E. (2026).
Modeling the Impact of Contamination on Microbial-Enzyme Dynamics and Soil Function.
bioRxiv. https://doi.org/10.64898/2026.10.07.757410

| File | Reproduces |
|---|---|
| soil_contamination_fig2_fig3.m | Figures 2–3, Table 2 (Section 3.1) |
| soil_contamination_fig4_fig5.m | Figures 4–5, Table 3 (Section 3.2) |
| soil_contamination_fig6_fig7.m | Figures 6–7, Table 4 (Section 3.3) |

Each script runs on its own in MATLAB (R2016b or newer), shows the figures,
and prints the final values to the Command Window.
Variable names follow Table 1 of the paper.
